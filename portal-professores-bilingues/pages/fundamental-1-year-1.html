Como usar esta página piloto

Mês a mês sem perder profundidade por disciplina

A navegação é mensal para facilitar o planejamento e a futura consolidação bimestral/trimestral. Dentro de cada mês, cada disciplina mantém campos próprios para evitar um resumo superficial: conteúdos, objetivos, vocabulário, language frames, evidências, prática/produção e conexão com report card.

Não misturar fontes

Somente Math e Science aparecem preenchidos nesta versão. Arquivos auxiliares de outras disciplinas não serão usados até validação.

Clareza para professores diferentes

Cada disciplina precisa ser compreensível isoladamente, porque nem sempre será ministrada pela mesma pessoa.

Preparação para report card único

As evidências de todas as disciplinas serão consolidadas depois em eixos comuns de desenvolvimento.

Unit 1 — Animals and plants alive!

Conteúdos / unidade

Seres vivos e não vivos; plantas como seres vivos; observação inicial de partes de plantas.

Objetivos de aprendizagem

Distinguir living/non-living; reconhecer que plantas são seres vivos; iniciar observações com apoio visual e concreto.

Vocabulário-chave

living, non-living, alive, plant, root, leaf, stem, flower, grow

Language frames

Is it living? / It is living. / It is non-living. / I can see a... / A plant has...

Habilidades observáveis

Classifica imagens/objetos em living/non-living; aponta partes de plantas; registra por desenho rotulado ou escolha guiada.

Sugestões de prática / produção

Sorting com objetos/imagens; mini-observação de plantas; desenho coletivo com labels.

Conexão com report card

Evidencia compreensão conceitual inicial, vocabulário científico receptivo e participação em investigação guiada.

MathFonte validada

Numbers to 10

Conteúdos / unidade

Contagem, leitura, escrita e comparação de quantidades até 10 com materiais concretos.

Objetivos de aprendizagem

Vocabulário-chave

number, count, one, two, three, four, five, six, seven, eight, nine, ten, more, fewer, same

Language frames

Sugestões de prática / produção

Number hunt, ten-frame, counting objects, matching numeral–quantity, oral counting routines.

Conexão com report card

Alimenta indicadores de number sense, participação matemática oral e uso funcional de vocabulário de quantidade.

Sharing and grouping

Conteúdos / unidade

Partilha e agrupamento de quantidades em contextos concretos, preparação para divisão/multiplicação informal.

Objetivos de aprendizagem

Formar grupos iguais; compartilhar objetos; explicar se a partilha é fair/equal; registrar agrupamentos.

Vocabulário-chave

share, group, equal, fair, each, altogether, left over, same

Language frames

Share equally. / Each group has... / It is fair/not fair. / There are... altogether.

Habilidades observáveis

Distribui objetos em grupos; identifica grupos iguais/não iguais; explica partilha com apoio; registra por desenho.

Sugestões de prática / produção

Sharing snacks/counters, equal group mats, classroom story problems, draw groups.

Conexão com report card

Contribui para indicadores de raciocínio multiplicativo inicial, colaboração, estratégia e explicação.

ScienceFonte validada

Review and investigation portfolio

Conteúdos / unidade

Retomada de unidades Science Year 1 com foco em pergunta, previsão, observação, registro e comunicação de descoberta.

Objetivos de aprendizagem

Consolidar linguagem científica; selecionar evidências; comunicar uma investigação simples com apoio.

Vocabulário-chave

question, predict, observe, record, result, same, different, because, evidence

Language frames

My question is... / I think... / I observed... / The result is... / I know because...

Habilidades observáveis

Portfólio com desenho/tabela/frase; apresentação curta; comparação previsão–resultado; autoavaliação simples.

Sugestões de prática / produção

Mini investigation fair, evidence folder, teacher conference, review games by unit.

Conexão com report card

Base direta para comentários de Science no report card: conceitos, investigação, linguagem e postura científica.

MathFonte validada

Fractions and geometry review · Statistics and problem solving

Conteúdos / unidade

Revisão de formas/frações; organização de dados; resolução de problemas e comunicação de estratégias.

Objetivos de aprendizagem

Retomar conceitos-chave; resolver problemas em contextos familiares; representar e explicar raciocínio.

Vocabulário-chave

shape, half, whole, data, problem, strategy, pattern, compare, explain, because

Language frames

I solved it by... / My strategy was... / I know because... / The pattern is... / The data shows...

Habilidades observáveis

Resolve problema com apoio; representa resposta; explica estratégia; interpreta dados simples; organiza portfólio matemático.

Sugestões de prática / produção

Problem-solving stations, shape/fraction review, class data project, math portfolio selection.

Conexão com report card

Base para comentários de Math no report card: conceito, procedimento, vocabulário, raciocínio e registro.

Próxima camada

Como esta matriz alimentará o report card único

O report card do Fundamental 1 não deve ser um relatório separado por disciplina. A proposta é consolidar evidências de English, Science, Math, Global Perspectives, PBL e Speaking Lab em eixos comuns de desenvolvimento do aluno.

English communication

Uso funcional da língua, compreensão oral, tentativas de fala, interação e language frames.

Content learning in English

Compreensão de conceitos de Science, Math e demais disciplinas ministradas em inglês.

Vocabulary and academic language

Reconhecimento e uso de vocabulário-chave, word banks e frases-modelo.

Task and project performance

Produções, registros, experimentos, resolução de problemas e projetos.

Thinking and reasoning

Prever, observar, comparar, justificar, explicar estratégia e revisar respostas.

Collaboration and learning habits

Participação, turn-taking, cuidado com materiais, autonomia e postura de aprendiz.
